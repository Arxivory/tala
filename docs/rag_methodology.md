# RAG methodology (planned)

Use a curated, traceable collection of scientific and authoritative sources.
Retain title, authors, year, DOI/URL and page/section metadata where available.
Retrieval should return source-linked passages. Generation should cite
retrieved evidence, distinguish evidence from interpretation, and abstain
when evidence is insufficient.

RAG is explanatory support. It does not diagnose, calculate biomechanics,
determine readiness or replace qualified medical/flight-surgeon judgment.
